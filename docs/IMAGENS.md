# Imagens

Área para guardar imagens de referência, em grade de colunas como o Pinterest, com grupos.

## O que é uma imagem

Tipo de post como os outros (`tipo: 'imagem'`): aparece no feed, na busca (Ctrl+K, pelo título e pela anotação), na tela da coleção (bloco Imagens), aceita comentário, favorito e “Mover para coleção”, e sincroniza entre aparelhos.

| Campo | Observação |
|---|---|
| Imagem | obrigatória; arquivo, colada ou por link |
| Título | opcional |
| Grupo | opcional; os grupos são só das imagens |
| Anotação | opcional; de onde veio, por que guardou |
| Coleção | a mesma lista do resto do sistema |

## Como entra uma imagem

- **Ctrl + V** com a tela de Imagens (ou qualquer tela, sem janela aberta e fora de um campo de texto) guarda a imagem copiada **na hora**. Com um grupo aberto, ela entra nele; dentro de uma coleção, entra nela.
- **Arrastar um arquivo** para a página faz o mesmo.
- **Guardar imagem** abre a janela com título, grupo e anotação. Nela dá para escolher o arquivo, arrastar, colar (Ctrl + V) ou colar um link no campo “link de uma imagem” (Enter ou **Usar**).
- Copiar uma imagem de uma página web e colar funciona; colar só o endereço de uma imagem fora de um campo também (nas telas que não são Imagens, só quando termina em `.png`, `.jpg` etc.).

**Link.** O app tenta baixar a imagem e guardar uma cópia reduzida (lado maior de 1200 px, JPEG). Se o site não permite a cópia, guarda só o endereço, e a imagem pode sumir se o site a tirar do ar; o aviso diz qual dos dois aconteceu.

## Em todo campo de imagem

O mesmo campo (escolher, arrastar, Ctrl + V ou link) vale para: capa de livro/filme, capa de pasta de estudos, foto do produto na wishlist (editar) e foto do perfil (“Trocar a foto”, agora uma janela). Capas e fotos são recortadas no tamanho do lugar; as imagens da área Imagens mantêm a proporção.

## Grupos

Chips acima da grade: **Todas**, um por grupo e **Sem grupo**, com a contagem. **+ Grupo** cria; com um grupo aberto aparecem renomear e excluir (as imagens continuam guardadas, só ficam sem grupo). **Arraste uma imagem sobre o nome de um grupo** para movê-la; “Mover para grupo” no menu “⋯” faz o mesmo.

## Visualizador

Clicar na imagem abre ela grande com título, anotação, origem e grupo. As setas (botões ou teclado) passam para a anterior e a próxima.

## Limites

As imagens ficam no armazenamento do navegador, como o resto. Cada uma sai em torno de 100 a 300 KB depois de reduzida; muitas imagens enchem o armazenamento (o aviso aparece) e a sincronização envia uma por vez. Quem guarda centenas deve exportar backups.

## Critérios de aceite

- Colar uma imagem na tela de Imagens e vê-la na grade.
- Colar um link de imagem no campo do formulário e ver a prévia.
- Criar um grupo, arrastar uma imagem para ele e filtrar pelo chip.
- Colar uma imagem no campo de capa de um livro.
- Trocar a foto do perfil colando uma imagem.
